[Koko Eating Bananas](https://neetcode.io/problems/eating-bananas)

```
class Solution:
    def minEatingSpeed(self, piles: List[int], h: int) -> int:
        left, right = 1, max(piles)

        while left < right:
            mid = left + (right - left) // 2
            hours = sum((pile + mid - 1) // mid for pile in piles)

            if hours <= h:
                right = mid
            else:
                left = mid + 1

        return left
```
