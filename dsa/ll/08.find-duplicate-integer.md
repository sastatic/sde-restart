https://neetcode.io/problems/find-duplicate-integer

```
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        seen = set()
        for num in nums:
            if num in seen:
                return num
            seen.add(num)
        return -1
```
Time Complexity: `O(n)`, Space Complexity: `O(n)`

```

class Solution:
    def findDuplicate(self, nums: list[int]) -> int:
        left = 1
        right = len(nums) - 1

        while left < right:
            mid = (left + right) // 2
            count = 0

            for num in nums:
                if num <= mid:
                    count += 1

            if count > mid:
                right = mid
            else:
                left = mid + 1

        return left
```
Time Complexity: `O(nlogn)`, Space Complexity: `O(n)`

```
class Solution:
    def findDuplicate(self, nums: list[int]) -> int:
        slow, fast = 0, 0
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        slow = 0
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
```
