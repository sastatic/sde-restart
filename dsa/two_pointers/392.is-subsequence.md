## Problem Link

[392. Is Subsequence](https://leetcode.com/problems/is-subsequence)

```py
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        i, j = 0, 0
        while i < len(s):
            if j >= len(t):
                return False
            if s[i] == t[j]:
                i += 1
            j += 1
        return True
```
