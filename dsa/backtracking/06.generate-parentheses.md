## Problem Link

[Generate Parentheses](https://neetcode.io/problems/generate-parentheses)

```
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        result = []
        def backtrack(braces, op, cp):
            if cp == n:
                result.append(braces)
                return
            if op == n:
                backtrack(braces+")", op, cp + 1)
            elif cp == op:
                backtrack(braces+"(", op + 1, cp)
            else:
                backtrack(braces+"(", op + 1, cp)
                backtrack(braces+")", op, cp + 1)
        backtrack("", 0, 0)
        return result
```
