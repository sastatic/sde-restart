## Problem Link

[647. Palindromic Substrings](https://leetcode.com/problems/palindromic-substrings)

```
class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        ans = 0
        def expand(l,r):
            nonlocal ans
            if l < 0 or r >= n or s[l] != s[r]:
                return
            ans += 1
            expand(l-1, r+1)
            
        for i in range(n):
            expand(i, i)
            expand(i, i + 1)
        return ans
```
