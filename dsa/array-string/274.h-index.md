## Problem Link

[274. H-Index](https://leetcode.com/problems/h-index)

```
class Solution:
    def hIndex(self, citations: list[int]) -> int:
        citations.sort()
        h_index, n = 0, len(citations)
        for i in range(n):
            papers_with_h_or_more_citations = n - i
            if papers_with_h_or_more_citations <= citations[i]:
                h_index = max(papers_with_h_or_more_citations, h_index)
        return h_index
```
