## Problem Link

[55. Jump Game](https://leetcode.com/problems/jump-game)

```
class Solution:
    def canJump(self, nums: list[int]) -> bool:
        maxReachable = 0
        for currentPosition in range(len(nums)):
            if currentPosition > maxReachable:
                return False
            maxReachable = max(maxReachable, currentPosition + nums[currentPosition])
        return True
```
