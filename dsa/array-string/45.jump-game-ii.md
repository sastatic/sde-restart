## Problem Link

[45. Jump Game II](https://leetcode.com/problems/jump-game-ii)

```
class Solution:
    def jump(self, nums: list[int]) -> int:
        jumps, current_end, farthest, n = 0, 0, 0, len(nums)

        for i in range(n - 1):
            farthest = max(farthest, i + nums[i])
            if i == current_end:
                jumps += 1
                current_end = farthest
                if current_end >= n - 1:
                    break

        return jumps
```
