## Problem Link

[206. Reverse Linked List](https://leetcode.com/problems/reverse-linked-list)

```
class Solution:
    def reverseList(self, head: ListNode | None) -> ListNode | None:
        if not head or not head.next:
            return head
        new_head = self.reverseList(head.next)
        head.next.next = head
        head.next = None
        return new_head
```
